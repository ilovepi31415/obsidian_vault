The Hypertext Markup Language (HTML) is a method for creating the layout of a webpage. It is arguably not its own coding language since it is so reliant on [[CSS]] and [[JavaScript]], but rather is just used to markup some of the basics.

HTML elements are nested within each other, creating the [[DOM Manipulation|Document Object Model (DOM)]]. This is the basis for many of the more advanced things that can be done with HTML
