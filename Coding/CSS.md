Cascading Style Sheets, or [[CSS]], is one of the three main languages used for website development, along with HTML and JavaScript. It formats the layout and order of the elements on the page

## CSS Cheat Sheet

### Terms to Know
- **Primary Axis**: The main direction in a flexbox; defaults to left->right^83c27f
- **Secondary Axis**: Perpendicular to the primary axis, defaults to up->down

### Some properties that I forget a lot
- `flex`
	- `align-items`: Orders content along the secondary axis
	- `flex-direction`: Sets the primary axis of the flexbox
	- `justify-content`: Orders content along the primary axis
